# Boutique Caschi Baldini — tema Shopify Online Store 2.0

**[Scarica il tema ZIP](https://github.com/boutiquecaschibaldini/e-commerce-boutique/blob/main/Baldini-tema-sezione-3D.zip)**: apri il file e premi **Download raw file** (icona download). Carica lo ZIP in **Shopify → Negozio online → Temi → Aggiungi tema → Carica file ZIP**, quindi apri l’anteprima.

Tema completo con nuova homepage, header, ricerca, categorie, filtri, pagine prodotto e carrello. La prima sezione mostra il casco reale a 360° con 48 fotogrammi del video e una scheda GLB illustrativa. Il modello GLB non è una replica esatta del prodotto.
